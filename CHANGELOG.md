## 0.0.1

* Initial release of `local_biometric`.
* Added support for Simple Biometric Authentication (`verifyPresence`).
* Added support for Encrypted Biometric Authentication with RSA/ECDSA signatures.
* Implemented proactive lockout detection on iOS.
* Unified behavior for passcode fallback across all biometric features.
* Added multi-page example app demonstrating all features.
* Standardized error codes across iOS and Android.
